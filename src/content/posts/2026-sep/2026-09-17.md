## About Signal

Signal 是在 Unix/Linux 當中，與 process 之間用來傳遞「非同步事件通知」的一套機制。我們可以透過 `kill` 指令，來向 process 發送訊號：

```bash
$ kill <process_id>      # 發送 SIGTERM 訊號 (沒有訊號參數的情況下)
$ kill -SIGINT <process_id> # 發送 SIGINT 訊號
```

有趣的是，我們最害怕的 `segmentation fault`，其實是當 Kernel 判斷這是非法的記憶體存取時，會向 process 發送 `SIGSEGV` 的訊號。

## Signal Disposition

當 process 收到 Signal 之後，會去查看 disposition 的紀錄，來決定他要怎麼處置。以 Linux 來舉例，當 process 建立時，每個 process 都會 signal handling 的相關狀態：

```
Process 1234 
┌──────────────────────┐
│ SIGINT → 0x401234    │ ← 自訂 handler
│ SIGTERM → SIG_DFL    │
│ SIGQUIT → SIG_DFL    │
└──────────────────────┘
```

我們甚至可以自己決定當收到訊號要怎麼做處置，以 c/c++ 來舉例，我們可以用 `signal(signal_name, handler)` 來定義處置的方式：

```C++
#include <signal>

void handler(int sig) {
    // ...
}

int main() {
    signal(SIGINT, handler);
}
```
